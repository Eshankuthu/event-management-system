# Event Management System

## Project Setup

### 1. Clone the Repository
First, clone the repository to your local machine.

```bash
git clone https://github.com/Eshankuthu/event-management-system.git
cd event-management-system

## 2. Install Dependencies
Install the required dependencies by running the following command:
npm install


## 3.  Create .env File
This project uses environment variables to configure the server and external API URLs.

To set up your environment, you need to create a .env file in the root directory of the project. You can copy the contents of the provided .env.example file or create the .env file manually.

Example .env file:
Create a .env file in the project root directory and add the following:
# .env
PORT=3000
API_BASE_URL=http://event.com


4. Start the Application
Once the .env file is set up, you can start the application using:
npm start
